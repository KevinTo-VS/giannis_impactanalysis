# Giannis Antetokounmpo Impact Analysis

This project analyzes Giannis Antetokounmpo's on-court impact using advanced basketball metrics to evaluate how valuable he is compared to other NBA forwards. Motivated by ongoing trade talks around Giannis, the goal is to answer the question, "Would acquiring Giannis meaningfully increase a team's championship enough to justify trading major assets? 

Using NBA advanced statistics on the years 2016-2022, I compare Giannis to other rotation-level forwards in the league across effiency and impact metrics such as Player Efficiency Rating (PER), True Shooting Percentage (TS%), Box Plus-Minus (BPM), and Win Shares (WS). The data collected helps to identify whether Giannis's value comes from scoring production alone or from consistent two-way impact that translates to winning.
